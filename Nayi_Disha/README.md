# Nayi Disha

**Nayi Disha** is a career and skill discovery platform that helps users explore training programs, skill development courses, and learning opportunities.
The project integrates a **modern React frontend**, **web scraping pipeline**, and **database configuration** to collect and present structured skill data.

---

## Tech Stack

**Frontend**

* React
* Vite
* TypeScript
* TailwindCSS

**Data Collection**

* Python
* Scrapy

**Backend / Database**

* Supabase

---

## Project Structure

```
Nayi_Disha-main

frontend/      # React application
scraper/       # Scrapy spiders and scraping pipeline
supabase/      # Database configuration
data/          # Collected datasets
README.md
```

---

## Setup & Run

### Install and start frontend

```
cd frontend
npm install
npm run dev
```

Application runs at:

```
http://localhost:5173
```

---

### Run the scraper

```
cd scraper
pip install scrapy
scrapy crawl skillindia
```
