# FounderLens AI

**AI-Powered Startup Problem-Solution Fit Analyzer**

## Objective
Helps early-stage founders validate their ideas by analyzing:
- Problem Clarity
- Solution Match
- AI Necessity

## Tech Stack
- **Frontend**: React + TypeScript + Shadcn/UI + Tailwind
- **Backend**: Supabase (Auth + Edge Functions)
- **AI/ML**: Sentence Transformers (Semantic Similarity)
- **Deployment**: Supabase + Vite

## How to Run

```bash
# Frontend
npm install
npm run dev

# Backend (Supabase)
supabase start
```

## Key Features

- Real-time AI analysis of startup ideas
- Problem Clarity Scoring
- Solution Match Score using custom ML model
- AI Necessity Classification
- Actionable Recommendations

## Demo

Run `python final_demo.py` to see the ML model in action.
